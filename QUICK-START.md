# NEON TETRIS - QUICK START

## HOW TO USE (3 Options)

### Option 1: PLAY NOW (Easiest)
Double-click: jogar.bat

### Option 2: DEVELOPMENT MODE
Double-click: start-dev.bat

### Option 3: CREATE WINDOWS .EXE
Double-click: build-windows.bat

### Option 4: CREATE ANDROID APK
Double-click: build-android.bat

---

## BEFORE STARTING

1. Install Node.js from: https://nodejs.org/
2. Extract project to a normal folder (NOT System32)
3. Run the .bat files from the project folder

---

## SCRIPTS

- jogar.bat = Open game in browser
- start-dev.bat = Start development server
- build-web.bat = Build web version only
- build-windows.bat = Create Windows .exe
- build-android.bat = Setup Android build

---

## CONTROLS

Arrow keys = Move/Rotate
Space = Hard drop
P = Pause
M = Sound on/off
Enter = New game

---

## PROBLEMS?

If you see errors:
1. Make sure Node.js is installed
2. Run script from project folder (not System32)
3. Try running as Administrator

---

Enjoy the game!
