# 🎮 Neon Tetris - Guia Completo de Funcionalidades

## ✨ Novas Funcionalidades Implementadas

### 🎨 1. Temas Visuais
Três temas completos para personalizar sua experiência:

- **Cyberpunk** (Padrão): Cores neon vibrantes com brilho intenso
- **Retro**: Paleta pastel com estética vintage
- **Minimalist**: Preto e branco elegante, sem distrações

**Como usar:** Menu → Settings → Theme

### 🎯 2. Modos de Jogo
Três modos diferentes para testar suas habilidades:

- **Marathon**: Jogo infinito, velocidade aumenta progressivamente
- **Sprint**: Complete 40 linhas o mais rápido possível
- **Ultra**: Máxima pontuação em 2 minutos cronometrados

**Como usar:** Menu → Selecione o modo desejado

### 🏆 3. Sistema de Conquistas
20 conquistas para desbloquear:

**Iniciante:**
- First Blood (1 linha)
- Getting Started (10 linhas)
- First Tetris (4 linhas de uma vez)

**Intermediário:**
- Centurion (100 linhas)
- Combo Starter (combo x3)
- Speed Demon (nível 5)

**Avançado:**
- Master Builder (500 linhas)
- Tetris Legend (10 Tetris)
- Combo Master (combo x5)
- Lightning Fast (nível 10)

**Mestre:**
- Combo God (combo x10)
- Unstoppable (nível 20)
- High Roller (100k pontos)

**Especiais:**
- Sprinter (complete o modo Sprint)
- Marathon Runner (30 minutos jogados)

**Como ver:** Menu → Achievements

### 📊 4. Leaderboard
Ranking dos seus melhores scores:

- Top 10 melhores pontuações
- Separado por modo de jogo
- Mostra nível, linhas e tempo
- Salvo localmente no navegador

**Como ver:** Menu → Leaderboard

### 🎵 5. Música de Fundo Dinâmica
Trilha sonora que se adapta ao modo de jogo:

- **Marathon**: Melodia relaxante em Dó maior
- **Sprint**: Ritmo acelerado em Ré maior
- **Ultra**: Tensão crescente em Dó menor

A música muda conforme o modo escolhido e pode ser desativada.

**Como usar:** Settings → Background Music

### 🎬 6. Sistema de Replay
Gravação automática das suas partidas:

- Salva todas as ações (movimentos, rotações, drops)
- Timestamp de cada ação
- Armazenado localmente
- Pronto para reprodução futura

**Nota:** A reprodução visual do replay será implementada na próxima versão.

### 📱 7. Controles Gestuais (Mobile)
Controle o jogo com gestos intuitivos:

- **Swipe Esquerda/Direita**: Mover peça
- **Swipe Para Baixo**: Hard drop (queda instantânea)
- **Tap**: Rotacionar peça
- **Long Press**: Guardar peça (hold)

**Como usar:** Funciona automaticamente em dispositivos touch

### 📳 8. Vibração Tátil (Mobile)
Feedback tátil para imersão total:

- Vibração leve ao mover peças
- Vibração média ao limpar linhas
- Vibração forte ao fazer combo
- Padrão especial ao fazer Tetris
- Vibração dramática no Game Over

**Como usar:** Settings → Vibration (Mobile)

## 🎮 Controles Completos

### Teclado (Desktop)
- `←` `→`: Mover peça
- `↑`: Rotacionar
- `↓`: Soft drop (queda suave)
- `Espaço`: Hard drop (queda instantânea)
- `C`: Guardar peça (hold)
- `P`: Pausar
- `M`: Ligar/desligar sons
- `Esc`: Voltar ao menu

### Touch (Mobile)
- **Swipe**: Mover e drop
- **Tap**: Rotacionar
- **Long Press**: Hold
- **Botões**: Controles na tela

## 📈 Sistema de Pontuação

### Pontuação Base
- 1 linha: 100 × nível
- 2 linhas: 300 × nível
- 3 linhas: 500 × nível
- 4 linhas (Tetris): 800 × nível

### Bônus
- **Combo**: +50 pontos por combo consecutivo
- **Hard Drop**: +2 pontos por célula caída
- **Soft Drop**: +1 ponto por célula caída

### Multiplicadores
- Nível aumenta a cada 10 linhas
- Velocidade aumenta com o nível
- Pontuação multiplicada pelo nível

## 🚀 Como Jogar

### Iniciante
1. Abra o jogo
2. Selecione um modo (recomendo Marathon)
3. Use as setas para mover
4. Seta para cima para rotacionar
5. Tente completar linhas horizontais

### Intermediário
1. Use o Hold (C) para guardar peças úteis
2. Planeje com o Ghost Piece
3. Tente fazer combos consecutivos
4. Explore os modos Sprint e Ultra

### Avançado
1. Domine todos os modos
2. Desbloqueie todas as conquistas
3. Busque o top 1 do leaderboard
4. Experimente todos os temas
5. Jogue sem sons para desafio extra

## 🎯 Dicas e Estratégias

### Básicas
- Mantenha o centro baixo
- Complete linhas regularmente
- Use o Ghost Piece para planejar
- Não entre em pânico quando a pilha subir

### Intermediárias
- Use Hold estrategicamente
- Priorize Tetris (4 linhas)
- Mantenha combos ativos
- Planeje 2-3 peças à frente

### Avançadas
- Domine wall kicks (rotações nas bordas)
- Faça T-Spins para bônus
- Mantenha a coluna da direita baixa para Tetris
- Gerencie o Hold com sabedoria

## 🐛 Problemas Comuns

### "O jogo não abre"
- Verifique se o Node.js está instalado
- Execute `npm install` na pasta do projeto
- Tente `npm run build` novamente

### "Sem som"
- Verifique se o som está ativado (M ou Settings)
- Verifique o volume do sistema
- Some navegadores bloqueiam áudio automático

### "Vibração não funciona"
- Only funciona em dispositivos móveis
- Alguns navegadores não suportam Vibration API
- Verifique as permissões do navegador

### "Conquistas não desbloqueiam"
- Jogue mais! Algumas conquistas são difíceis
- Verifique o menu Achievements
- Os dados são salvos localmente

## 🎓 Curiosidades

### Tetris Original
- Criado em 1984 por Alexey Pajitnov
- Nome vem de "tetra" (4) + "tênis" (esporte favorito)
- 7 peças diferentes (tetrominós)
- Jogo mais vendido da história

### Recordes Mundiais
- Maior pontuação: 999,999 (limite do jogo original)
- Mais linhas: 255 (limite do contador)
- Tetris mais rápido: 40 linhas em ~1 minuto

### Este Jogo
- Feito com React + TypeScript
- Web Audio API para sons
- Canvas para partículas
- LocalStorage para dados
- Totalmente responsivo
