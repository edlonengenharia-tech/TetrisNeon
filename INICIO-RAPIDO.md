# 🎮 NEON TETRIS - INÍCIO RÁPIDO

## 🚀 Como Jogar (3 Opções)

### Opção 1: JOGAR AGORA (Mais Fácil) ⭐
**Duplo clique no arquivo:** `jogar.bat`

O jogo abrirá automaticamente no seu navegador!

---

### Opção 2: MODO DESENVOLVEDOR
**Duplo clique no arquivo:** `start-dev.bat`

Abre o servidor de desenvolvimento com hot reload.

---

### Opção 3: CRIAR EXECUTÁVEL WINDOWS (.exe)
**Duplo clique no arquivo:** `build-windows.bat`

Cria um arquivo .exe que você pode executar sem navegador.

---

## 📋 Antes de Começar

### ✅ Verifique se você tem:

1. **Node.js instalado**
   - Baixe em: https://nodejs.org/
   - Instale a versão LTS
   - Reinicie o computador após instalar

2. **Projeto em uma pasta normal**
   - ✅ Exemplo: `C:\NeonTetris`
   - ❌ NÃO use: `C:\Windows\System32`

---

## 🎯 Passo a Passo (Para Iniciantes)

### Passo 1: Instalar Node.js
1. Acesse: https://nodejs.org/
2. Clique no botão verde "LTS" (recomendado)
3. Execute o instalador
4. Clique em "Next" até terminar
5. **Reinicie o computador**

### Passo 2: Extrair o Projeto
1. Extraia o arquivo ZIP do projeto
2. Coloque em uma pasta fácil de acessar
3. Exemplo: `C:\NeonTetris`

### Passo 3: Jogar!
1. Abra a pasta do projeto
2. **Duplo clique** em `jogar.bat`
3. Aguarde o navegador abrir
4. Divirta-se! 🎮

---

## ❓ Problemas?

### "Node.js não encontrado"
- Instale o Node.js: https://nodejs.org/
- Reinicie o computador
- Tente novamente

### "package.json não encontrado"
- Você está executando o script na pasta errada
- Navegue até a pasta do projeto primeiro
- Depois execute o script

### "Build falhou"
- Verifique sua conexão com a internet
- Execute o terminal como administrador
- Tente novamente
